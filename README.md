## 🌟 نبذة عن المشروع (About the Project)

**مكتبة أفق المتنقلة** هو تطبيق ويب متكامل وحديث تم بناؤه باستخدام **Next.js** و **React** و **Tailwind CSS**. يهدف المشروع إلى تقديم تجربة فريدة وممتعة لمحبي القراءة من خلال تمكينهم من استكشاف الكتب، استعارتها أو شرائها، وتتبع مسار الحافلة الخاصة بالمكتبة المتنقلة في الوقت الفعلي عبر الخرائط التفاعلية.

يتميز التطبيق بدعمه الكامل للثنائية اللغوية (العربية والانجليزية) مع واجهة مستخدم ذات حركات وتفاعلات سلسة (Framer Motion) تدعم الوضعين الداكن والمضيء بشكل تلقائي وتفاعلي.

---

## 🎨 استعراض الأوضاع (Light / Dark Mode Showcase)

تم دمج صورتين للموقع (الوضع المضيء والوضع الداكن) داخل ملف **SVG** متحرك تفاعلي يظهر في مقدمة هذا الملف. 
* **كيف يعمل الأنيميشن؟** يتم دمج الصورتين بنظام التشفير (Base64) داخل ملف الـ SVG مع استخدام حركات CSS Keyframes لعمل تلاشي (Fade transition) مستمر وتلقائي يعمل مباشرة على GitHub دون الحاجة لأي مكتبات خارجية أو جافا سكريبت!

## 🚀 أبرز المميزات (Key Features)

### 🗺️ 1. خريطة مسار المكتبة المتنقلة (Interactive Route Map)
* تتبع مسار حافلة المكتبة المتنقلة ومحطاتها المجدولة على الخريطة التفاعلية باستخدام **Leaflet Maps**.
* حركات مخصصة وتفاعلية للمؤشرات (Markers) وخطوط المسار (Polylines) لسهولة المتابعة.

### 🌐 2. نظام ثنائي اللغة بالكامل (Bilingual RTL/LTR)
* دعم كامل للغتين **العربية (RTL)** و **الإنجليزية (LTR)**.
* تبديل سلس ولحظي للغة مع تعديل اتجاه الصفحات والقوائم تلقائياً دون إعادة تحميل الصفحة.

### 🛒 3. نظام استعارة وشراء الكتب (E-Commerce & Borrowing)
* **سلة مشتريات تفاعلية (Cart Drawer)** تنزلق بسلاسة لإدارة الكتب المضافة للشراء أو الاستعارة.
* **مساعد الدفع (Checkout Wizard)** يمرر المستخدم عبر خطوات الدفع والشحن والاستعارة بحركات انسيابية.
* قائمة المفضلة لحفظ الكتب وقراءة تفاصيلها لاحقاً.

### 🎙️ 4. مشغل صوتي مدمج (Audio Book Player)
* إمكانية الاستماع للكتب الصوتية أو ملخصات الكتب من خلال مشغل صوتي مدمج وتفاعلي.

### 📊 5. لوحة تحكم الإدارة الشاملة (Admin Dashboard)
* إدارة كاملة للمحتوى: إضافة، تعديل، وحذف الكتب والتصنيفات.
* تتبع وإدارة عمليات الاستعارة والشراء والمستخدمين.
* تحديد وتحديث مسارات الحافلة ومحطاتها على الخريطة مباشرة.

### 🎭 6. حركات وتفاعلات غامرة (Stunning Animations)
* انتقالات ممتازة بين الصفحات، وتأثيرات ظهور تدريجي عند التمرير (Scroll Reveal).
* تفاعلات ديناميكية للمؤشر (Custom Cursor)، وتأثيرات حركية تفاعلية للأزرار وبطاقات الكتب عند المرور عليها بالماوس.
* محرك ذكي يدعم **تقليل الحركة (prefers-reduced-motion)** للحفاظ على سهولة الوصول والتصفح السلس للجميع.

## 🛠️ التقنيات المستخدمة (Tech Stack)

| التقنية | الاستخدام |
| :--- | :--- |
| **Next.js 14 (App Router)** | إطار العمل الأساسي للويب وسرعة التحميل والـ SEO |
| **React** | بناء المكونات التفاعلية والواجهات |
| **Tailwind CSS** | التنسيقات وتصميم واجهات متجاوبة وعصرية |
| **Framer Motion** | إنشاء التفاعلات والحركات الاحترافية وسلسلة الانتقالات |
| **TypeScript** | ضمان أمان الكود ونمذجة البيانات بدقة |
| **Leaflet & React Leaflet** | رسم وتخصيص الخرائط التفاعلية وتتبع مسار الحافلة |
| **Next Themes** | إدارة وتغيير سمات الموقع (Light/Dark Mode) |
| **Lucide React** | مكتبة أيقونات عصرية ومتجاوبة |

## 📂 هيكل المجلدات (Project Directory Structure)

```bash
ofoq-library/
├── public/                 # الملفات العامة والصور وأيقونات الموقع
│   └── images/             # صور الكتب، الشعارات، وملف العرض المتحرك (ofoq-showcase.svg)
├── src/
│   ├── app/                # صفحات التطبيق (App Router) والتوجيه (Routing)
│   ├── components/         # مكونات واجهة المستخدم (الخريطة، السلة، بطاقات الكتب، إلخ)
│   ├── contexts/           # سياقات العمل (State Management: السلة، المفضلة، اللغات)
│   ├── data/               # بيانات افتراضية وقوائم الكتب والمسارات
│   ├── hooks/              # خطافات مخصصة (Custom Hooks) مثل useReducedMotion
│   ├── translations/       # ملفات الترجمة للغتين (ar.json / en.json)
│   ├── types/              # تعريفات الأنواع لـ TypeScript
│   └── utils/              # دوال مساعدة عامة
├── tailwind.config.js      # إعدادات وتخصيصات Tailwind CSS
└── package.json            # الاعتماديات والسكربتات المشغلة للمشروع
```

## 🚀 طريقة التشغيل والتثبيت (Getting Started)

لتشغيل المشروع محلياً على جهازك، يرجى اتباع الخطوات التالية:

### 1. استنساخ المستودع (Clone the Repository)
```bash
git clone https://github.com/AhmedSaadRF/Library-Website.git
cd Library-Website
```

### 2. تثبيت الاعتماديات (Install Dependencies)
```bash
npm install
```

### 3. تشغيل خادم التطوير (Run Development Server)
```bash
npm run dev
```
افتح الرابط [http://localhost:3000](http://localhost:3000) في متصفحك لمشاهدة الموقع.

### 4. بناء نسخة الإنتاج (Build for Production)
```bash
npm run build
npm start
```
